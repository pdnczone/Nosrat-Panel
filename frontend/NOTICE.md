# Notice

**Nosrat** is a rebranded and substantially redesigned fork of the frontend
of [Smite](https://github.com/zZedix/Smite), an open-source tunnel/server
management panel originally created by **zZedix**, distributed under the
MIT License (see `LICENSE`).

This fork:
- Replaces all "Smite" branding, logos, and UI copy with the "Nosrat" identity.
- Introduces a new "liquid glass" visual design system and component library.
- Adds a Node Management area, including an SSH-based remote installation
  wizard (frontend + documented API contract only — see
  `NOSRAT_BACKEND_CONTRACT.md`).

The MIT License permits this kind of modification and redistribution as long
as the original copyright notice and license text are preserved, which is
why both are kept in this repository even though the upstream project isn't
credited in the live UI itself.
